# Караоке-плеер

Компактный настольный караоке-плеер на Python с интерфейсом на PySide6.

## Возможности

- открывает папку с библиотекой песен или несколько аудиофайлов;
- поддерживает структуру библиотеки, где каждой песне соответствует отдельная папка;
- показывает плейлист слева;
- отображает синхронизированный LRC-текст в основной области;
- поддерживает воспроизведение, паузу, остановку, переход к предыдущей и следующей песне;
- умеет перематывать трек слайдером и стрелками клавиатуры;
- показывает понятные сообщения об ошибках;
- содержит тесты для парсинга, синхронизации и логики плейлиста.

## Стек

- Python 3.11+
- PySide6
- pytest
- coverage

## Установка

```bash
python -m venv .venv
source .venv/bin/activate  # Linux/macOS
# .venv\Scripts\activate   # Windows
pip install -r requirements.txt
```
## Запуск

Если запустить приложение без аргументов, оно по умолчанию загрузит песни из папки songs/ в корне проекта.
```
python -m karaoke_player
```
Можно явно передать папку с библиотекой:
```
python -m karaoke_player ./songs
python -m karaoke_player /path/to/my-library
python -m karaoke_player --help
```
Можно передать и отдельные аудиофайлы:

```
python -m karaoke_player ./songs/demo1.mp3 ./songs/demo2.mp3
```
## Рекомендуемый формат библиотеки

Рекомендуемая структура для этого проекта:

```
songs/
├── Исполнитель - Название/
│   ├── track.mp3
│   └── track.lrc
├── Другой исполнитель - Другая песня/
│   ├── song.mp3
│   └── song.lrc
```
## Правила:

- стартовая папка содержит по одной подпапке на каждую песню;
- в папке песни должен быть ровно один поддерживаемый аудиофайл;
- файл .lrc необязателен, но очень желателен;
- если у .lrc такое же базовое имя, как у аудиофайла, он подхватится автоматически;
- если имена различаются, загрузчик всё равно возьмёт первый найденный .lrc в папке песни.

Для обратной совместимости поддерживается и плоская структура:
```
songs/
├── song.mp3
└── song.lrc
```
## Формат LRC

Пример:
```
[00:05.00]Первая строка
[00:10.40]Вторая строка
[00:15.00]Третья строка
```
## Горячие клавиши
```
Space — воспроизведение / пауза
Left — перемотка назад на 5 секунд
Right — перемотка вперёд на 5 секунд
```
